# مكتبة دار الوليد — متجر الكتب

متجر إلكتروني ثنائي اللغة (عربي/إنجليزي، RTL) لمكتبة دار الوليد في طرابلس، ليبيا.

- **تسعير حسب الموقع تلقائياً:** داخل ليبيا بالدينار الليبي (د.ل)، وخارجها بالدولار الأمريكي ($) — يُكشف الموقع في الخلفية.
- **الطلب عبر واتساب:** يُحفظ الطلب ثم يُفتح واتساب برسالة منظّمة.
- **لوحة إدارة:** الكتب (مع رفع صور الأغلفة والاستيراد المجمّع CSV/JSON)، الطلبات، والإعدادات (سعر الصرف + رسوم الشحن).

## التشغيل محلياً

موقع ثابت بلا خطوة بناء — يكفي خادم ملفات:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> ملاحظة: يجب التشغيل عبر HTTP (وليس فتح الملف مباشرة) لأن JSX يُترجم في المتصفّح عبر Babel.

## التقنية

HTML + CSS + React (عبر CDN) مع ترجمة JSX في المتصفّح عبر `@babel/standalone`. الحالة تُحفظ في `localStorage`.
